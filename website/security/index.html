Security & trust, stated plainly

Opening an HTML file from the internet should be as safe to inspect as a web page, while software you build and trust should save without friction. Here is the exact boundary HTML Clay enforces on your machine.

Three-tier document trust model

Document trust follows both where a file came from and whether its executable code has changed, rather than relying on folder location alone.

1. Your own files & trusted folders

Files you created locally and documents inside folders you marked Trusted open directly at a stable local origin, write atomic saves back into their file, and keep version history automatically.

Trusted folder Direct atomic save

2. Signed ecosystem apps

Official starter apps carry a detached cryptographic signature (ecosystem-2026-11) verified completely offline against their code. If the signature matches, they open ready to save with no nag screen; if tampered with, they drop to untrusted.

Offline signature check ecosystem-2026-11

3. Downloaded & unknown files

Quarantined downloads, files without an origin record, or files whose code changed outside HTML Clay are isolated on their own per-document browser origin. They open read-only first, ask before saving, and never auto-run helper programs.

Isolated origin Read-only until trusted

Program approval designed against accidental clicks

An approved local helper program runs as your OS user account: it can read or modify files you can access and reach the network. Because that crosses out of the browser sandbox, HTML Clay treats program setup with strict, verifiable rules:

  • Binary identity pinning: HTML Clay records the target file's identity before opening the dialog. If the file on disk is swapped or replaced during approval, execution is refused.
  • No default Return-key button: pressing Return or Space by reflex never approves a program. You must explicitly click Allow.
  • Blocked auto-suggest locations: HTML Clay never suggests a binary from the document's own folder, Downloads, temporary directories, files modified in the last 10 minutes, or raw shell/script interpreters (sh, python, node).
  • Dialog rate-limiting & instant revocation: dismissing or denying a request stops page-raised prompts from nagging you, and revoking a grant in Settings takes effect immediately.
Native macOS Program Consent

Localhost boundary, privacy, and verification

Concrete facts you can check yourself with lsof, a packet monitor, or the public repository.

Localhost-only server (127.0.0.1)

HTML Clay binds strictly to loopback (127.0.0.1), never exposes ports to your LAN, never serves files outside your home folder, refuses dotfiles, and sends zero CORS headers, so outside websites in other tabs cannot read or write your documents.

AI editing consent & data boundary

Pressing ⌘J sends only the selected HTML, your prompt, and ordinary @file attachments from a trusted document's own folder (refusing dotfiles and symlinks out) to your configured CLI tool, which talks to its own model provider. Turn AI editing off anytime in Settings.

Zero telemetry & no account required

The desktop app collects no usage analytics, crash telemetry, or document titles, and requires no login. Network traffic occurs only for signed update checks (unless disabled) or if you explicitly connect a Hyperclay sync key.

Data-loss guard & Kept Copies

Saves, JSON API writes, and external disk changes are checked against data-guard-v2. Unconditional writes that would wipe values without a matching If-Match ETag are refused with 428, and replaced versions are pinned in Kept Copies.

Apple Notarization & Windows code signing

Every macOS Universal release is signed with a Developer ID certificate, notarized by Apple, and updated via signed Sparkle feeds. Windows x64 and ARM64 binaries are Authenticode-signed and install in user space without administrator elevation.

Open source & SHA-256 verifiable

Inspect the Go host, data API selector gate, and protocol conformance suite on GitHub, and verify every release archive against our published SHA256SUMS manifest.

Verify your download
