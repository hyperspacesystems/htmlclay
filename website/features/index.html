What HTML Clay does on your computer

HTML Clay turns plain HTML files into personal software you can keep and modify, pairing a quiet menu-bar companion with live sync across editors and tabs, built-in AI editing, local scripts, and careful disk safety.

HTML Clay stays out of your Dock and your Cmd-Tab switcher. Click its menu-bar icon whenever you want to reopen a recent file, jump into your local browser dashboard, review two-way sync edits, answer a pending helper program request, or pause syncing.

Calculator documents & JSON over HTTP

Any .html or .htmlclay file served by HTML Clay doubles as a structured JSON endpoint on localhost. Pass CSS extraction rules in the query string or declare an api rules tag inside the document itself.

When a script updates inputs on a worksheet or calculator document, append ?recalculate=wait: HTML Clay lets an open tab (or a brief, origin-locked headless Chromium window) run the page's formulas, save the fresh state, and return recalculated totals in one round trip.

  • Optimistic concurrency: every read returns an ETag; writes with If-Match refuse stale overwrites with 412.
  • Content-only splicing: writes touch only matched text, safe attributes, or canonical sheet grids, never injecting scripts or event handlers, while leaving untouched bytes intact.

Tiny things you might notice

Small engineering guarantees behind opening, saving, versioning, and keeping your files intact on disk.

1. Opening is strictly read-only

A file you double-click and never save is never modified on disk, and temporary history for unopened one-off views is cleaned up after a week.

2. Atomic temp-file saves

Every save writes and flushes a temporary file first, renames it atomically over the target, and flushes the parent directory on macOS and Linux before reporting success.

3. Clean HTML on disk

Session attributes (savetoken, documentetag, and local runtime projections) are stripped before bytes reach disk, so your file stays portable HTML.

4. Kept Copies & outside-edit backups

If an outside edit or script removes data, HTML Clay pins a backup copy in Kept Copies and offers an in-page Put it back / Restore bar that survives restarts.

5. Duplicate snapshots collapse

Saving identical bytes twice in a row never clutters version history, and your own save is hash-suppressed so the file watcher never echoes it back at your tab.

6. Stable htmlclay.localhost:1212 addresses

Every served folder gets a durable local hostname on one shared port so browser bookmarks, storage, and cross-file links keep working after reboots.

7. Bundled offline ClayJS runtime

Documents referencing clayjs.com load the exact bundled ClayJS runtime locally from /_/clayjs/ with zero internet required and unchanged disk ETags.

8. Offline Tailwind v4 compiler

Link /tailwindcss/<name>.css and HTML Clay compiles Tailwind v4.1.17 (with typography and forms) locally from the classes your document uses, cached by fingerprint.

9. Updates keep your open tabs

Restarting to apply an update preserves every open document's address, save token, and grants, and automatically rolls back if an update ever fails to launch.

10. One-click ZIP export with assets

Export any open document and its companion assets-<name> uploads folder into a clean .zip in Downloads whenever you want to send a project to someone else.
