Installing on each platform

First-run setup takes a few seconds and associates .htmlclay files with your account.

macOS

Open the downloaded .dmg, drag HTML Clay into Applications, and launch it once. HTML Clay registers the .htmlclay file type in Finder and places its icon in your menu bar.

Windows

Unzip the archive anywhere you like and double-click htmlclay.exe once. It registers .htmlclay files for your Windows user account with no administrator prompt and runs quietly in the system tray.

Linux

Unpack the tarball and run bash install.sh, which installs into ~/.local/bin and registers the desktop entry without sudo.

Desktop dialog note: permission prompts use zenity or kdialog. With neither installed, untrusted files outside trusted folders are safely refused rather than prompted; trusted folders work either way.

Checking what you downloaded

Compare the output of your operating system's built-in SHA-256 tool against the hash copied above or the full SHA256SUMS file.

# macOS
shasum -a 256 ~/Downloads/HTMLClay-*.dmg

# Windows (Command Prompt or PowerShell)
certutil -hashfile htmlclay-windows-amd64.zip SHA256

# Linux
sha256sum htmlclay-linux-amd64.tar.gz
